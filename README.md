# Ростер гильдии

Статическое веб-приложение для учёта игроков гильдии (режим 30×30).  
Хостится на GitHub Pages — открывается мгновенно, без регистрации.

---

## Как обновить ростер

### 1. Добавить / изменить игрока

Откройте файл `data.js`. В массиве `PLAYERS` добавьте или отредактируйте запись:

```js
const PLAYERS = [
  {
    name:      "NickName",  // игровое имя
    build:     "tank",      // ключ из BUILDS (обязательно)
    altBuild:  null,        // ключ из BUILDS или null
    gearLevel: 2100,        // уровень шмота (число)
    ready:     true,        // готов на бой 30×30 (true / false)
    note:      "фокус"      // тактическая заметка или пустая строка ""
  },
  // ... остальные игроки
];
```

> Значения `build` и `altBuild` должны совпадать с ключами объекта `BUILDS`.

---

### 2. Добавить / изменить билды и цвета

Найдите объект `BUILDS` в начале `data.js`:

```js
const BUILDS = {
  tank:    { label: "Танк",       color: "#3b82f6" },
  healer:  { label: "Хилер",      color: "#22c55e" },
  // добавьте свои билды здесь
};
```

- `label` — отображаемое название.
- `color` — цвет бейджа в формате hex.

Фильтры, легенда и цветовая кодировка **обновляются автоматически** при изменении `BUILDS`.

---

### 3. Сохранить и опубликовать

```bash
git add data.js
git commit -m "Обновил ростер"
git push origin main
```

GitHub Pages обновится в течение нескольких секунд.

---

## Деплой на GitHub Pages

1. Перейдите в **Settings → Pages** вашего репозитория.
2. Source: **Deploy from a branch**.
3. Branch: **main**, папка: **/ (root)**.
4. Нажмите **Save**.
5. Сайт будет доступен по адресу:  
   `https://<user>.github.io/<repo>/`

---

## Структура файлов

```
index.html  — разметка страницы
style.css   — тёмная тема, адаптивная вёрстка
app.js      — логика (фильтры, сортировка, режимы просмотра)
data.js     — данные игроков и конфиг билдов ← редактировать здесь
README.md   — этот файл
```
